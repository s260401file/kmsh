# 壹、文件說明

本系統採前後端分離架構：後端為 .NET 8 MVC Web API＋Dapper 資料存取；前端為 React／Vite 單頁應用；另含兩支資料同步主控台程式 WhiteboardSync／DbSync；資料庫為 SQL Server。

本清單逐一列出四個專案之原始碼檔案及其用途，並依資料夾／分層分組。已排除建置產物與自動產生檔案（含 obj／bin／node_modules／dist／.vs 等目錄，以及 *.g.cs、AssemblyInfo、GlobalUsings、WeatherForecast 範本檔）。前端各站看板之靜態展示 mock 資料（tabsData\ 與 mockData.js，開發階段用）不逐檔列出，僅於各站以一列摘要。後端資料庫 SQL 腳本亦不逐檔列出，詳見另冊《資料庫預存程序清冊》。

**專案結構總覽**

| 專案名稱 | 技術 | 用途 |
|---|---|---|
| 後端 API（kmsh-whiteboard） | .NET 8 MVC Web API＋Dapper | 對接院方 HIS、聚合看板資料、後台管理與稽核之 API 服務 |
| 資料同步 WhiteboardSync | .NET 8 主控台程式 | 將資訊室同步庫 DB2_DUMP 清洗後落地本地 Whiteboard 庫 |
| 資料同步 DbSync | .NET 8 主控台程式 | 將真實 DB2（HIS）增量同步至 SQL Server 之 DB2_DUMP 庫 |
| 前端 React | React／Vite | 四站護理白板（W52／ICU／OR／ER）顯示端與管理後台 |

## DbSync（真實 DB2 → SQL Server DB2_DUMP 增量同步）

專案根目錄：DbSync\

| 檔案 | 說明 |
|---|---|
| Program.cs | 進入點：命令列參數、層別 Mutex 防重疊、退出碼判讀 |
| SyncEngine.cs | 依層別挑出啟用表逐表同步，單表失敗不中斷其他表 |
| TableSyncer.cs | 單表同步核心：暫存表流程（重建→BulkCopy→MERGE→清除） |
| Db2Source.cs | 來源端（DB2／HIS）讀取封裝，產生 SELECT 回傳 IDataReader |
| SqlTarget.cs | 目標端（DB2_DUMP）寫入封裝：暫存表、BulkCopy、MERGE |
| KeyInspector.cs | 唯讀診斷：查詢 DB2 主鍵／唯一索引以校正 KeyCols |
| WatermarkStore.cs | 浮水印狀態（每表最後同步值），以本機 JSON 檔保存 |
| AppConfig.cs | 組態模型（對應 appsettings.json 的同步表設定） |
| Logger.cs | 檔案／主控台記錄器 |
