# 壹、專案概述
本報告為「高雄市立民生醫院護理科電子白板系統」之結案報告，總結專案執行成果、交付項目、測試與驗收、教育訓練、需求變更、資訊安全與保固維護等事項，作為專案結案之依據。

- **專案目的：** 以病人為中心建設智慧病房，優化住院照護體驗、簡化醫護工作流程，落實「將時間還給醫護人員，將醫護人員還給病患」之優質護理服務。
- **建置範圍（第一階段）：** W52 一般病房、ICU 加護病房、OR 手術室、ER 急診室等 4 個護理站之電子白板顯示端與後台管理功能。
- **依據：** 需求規格書（中華民國 115 年 02 月 09 日）、契約、工作計畫書及系統需求確認書。

# 貳、執行成果總述
第一階段 4 個護理站之電子白板系統已依系統需求確認書完成建置並展示，功能涵蓋病室動態、照護提醒、手術資訊、檢查／會診、排班與值班資訊、佈告與避難圖、護理交班等，並完成後台管理、值班醫師中央排程、帳號與權限管理等共通功能。

- **技術架構：** 採前後端分離——後端 .NET 8 MVC Web API（Dapper 存取 SQL Server）、前端 React 響應式網站（RWD），並以資料同步（ETL）將院方電子白板來源資料清洗落地，供白板查詢。
- **介接：** 引用 HIS 資料表結構定義，未開放欄位以自建後台過渡；介接院方電子白板 API（手術／病床）；帳號與本院 AD／SSO 整合。

# 陸、測試與驗收
- 依測試計畫書執行單元、整合、系統及使用者測試，測試項目之預期結果均達成，缺失依分級修正並回歸測試結案。
- **效能：** 線上作業查詢回應時間抽樣量測不超過 5 秒。
- **可用率：** 符合接獲通知 2 小時內連線處理、必要時 4 小時內到場、12 小時內回復正常運作之服務水準。
- 測試結果彙整於測試報告書；使用者測試由本院使用者確認功能符合作業需求。

# 柒、教育訓練
- 依教育訓練計畫書辦理教育訓練，對象包含本院使用者及資訊人員，內容涵蓋白板顯示端操作、後台維護作業及系統管理維運。
- 提供教育訓練教學光碟，供後續人員自主學習與新進人員訓練之用。

# 捌、需求變更情形
- 專案執行期間之需求變更依「需求變更確認書」程序辦理，逐筆評估功能支數、時程、資源與測試範圍之影響並經雙方確認。
- 各階段需求變更控管於系統總功能支數 10%（約 3 支）之免計費範圍內；主管機關來函變更不計入。

# 玖、資訊安全與權限
- 帳號角色透過本院 AD 整合維護並與 SSO 整合；權限採角色組合之階層式授權。
- 顯示端匿名可讀；任何新增／修改／刪除均須登入授權，並記錄稽核軌跡（異動帳號、時間；登入、登出、登入失敗事件）。
- 使用者閒置達設定時間自動登出；對外服務支援 SSL；資料存取全面參數化查詢。
- 依「資訊系統分級與資安防護基準」及本院 ISMS 辦理。

# 拾、保固與維護
- 軟體保固期 1 年、硬體保固期 3 年；保固期間配合問題檢測、效能調校及基本操作教學。
- 保固期間所增修功能以系統總功能支數 10% 範圍內為限（不含主管機關來函變更）。
- 保固期滿日前如線上回應時間超過規範，於一個月內免費調整完成。

# 拾壹、後續階段建議
- **第二階段：** 洗腎室擴充功能，及其餘 12 個護理站電子白板系統建置。
- **資料源切換：** HIS 相關欄位開放後，將自建後台過渡資料切換為 HIS 資料源，白板顯示無縫接軌。
- 持續配合院方 HIS／電子白板 API 結構異動維護欄位對照。

# 拾貳、結論
第一階段 4 個護理站電子白板系統已依需求規格書與系統需求確認書完成建置、測試與教育訓練，交付項目齊備。本專案第一階段目標達成，經雙方確認後辦理結案；第二階段依契約期程另行建置。
