# 壹、目的與依據
本計畫書依「高雄市立民生醫院護理科電子白板系統」需求規格書及契約之教育訓練需求編撰，說明訓練目標、對象、課程規劃、講師與資歷、場地、教材、時程、簽到與成效評量等，作為本專案教育訓練執行之依據。訓練時間由本院資訊室與廠商協定；課程規劃於提出後與本院共同討論確定。

# 貳、訓練目標
- 使一般人員（護理科及各科室相關人員）熟悉四站電子白板之操作與後台設定，能獨立完成日常維護作業。
- 使資訊人員了解系統架構、資料介接、部署維運與資訊安全機制，具備後續維護與問題排除能力。

# 參、訓練對象與場次
本院提列之最低限度課程如下表，廠商得依專業規劃增加課程數量：

| 授課對象 | 課程名稱 | 場次 |
|---|---|---|
| 一般人員 | 應用系統相關作業操作課程 | 3 場次 |
| 資訊人員 | 應用系統相關開發課程 | 2 場次 |

- 一般人員實際受訓人數以報名人數為主，場地由本院提供。
- 資訊人員受訓人數為資訊室相關人員，實際人數以當天出席人數為主。

# 肆、課程規劃與大綱
## 一、一般人員：應用系統操作課程（每場約 3 小時）
- 系統概觀與登入（AD 帳號登入、權限說明、閒置自動登出）。
- 四站看板操作：W52 一般病房、ICU 加護病房、OR 手術室、ER 急診室之頁籤與畫面說明。
- 後台設定實作：跑馬燈、佈告欄公告、連絡電話、排班資訊（含負責床位/緊急應變編組/點班）、檢查/會診（以在床病人逐一設定）、病人臨床補充、避難圖等。
- 資料維護原則：以在床病人為主之設定流程、24 小時自動移除機制、常見問題與異常通報。
## 二、資訊人員：應用系統開發課程（每場約 3 小時）
- 系統架構：Windows Server 2022／IIS／.NET 8（MVC）／SQL Server 2022／React 前端。
- 資料介接：與 HIS 之欄位對照、自建後台資料源與切換策略、資料同步機制。
- 部署與維運：IIS 站台與 API 佈署、資料庫維護、備份與復原作業。
- 帳號與資安：AD／SSO 整合、role-base 權限、操作稽核與登入稽核、弱點修補與更新流程。
