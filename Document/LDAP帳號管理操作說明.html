LDAP 帳號管理操作說明

護理科電子白板系統　·　AD LDS（Windows 內建輕量 LDAP）@ 101 主機

帳號＝員編　·　登入／登出留存（可勾稽）　·　帳號管理需系統管理員權限
這是什麼：白板管理後台的登入帳號存放於本院 101 主機上的 AD LDS（Windows 內建輕量 LDAP 目錄，非網域控制站）。使用者以「員編＋密碼」登入白板後台，白板只透過 LDAP 驗證密碼；帳號的增／刪／查／改在此以 PowerShell 工具進行。
連線127.0.0.1:3890（本機） 帳號位置OU=people,DC=kmsh,DC=local；每人 DN＝CN=<員編>,OU=people,DC=kmsh,DC=local 管理工具C:\kmsh-ldap\ldap-admin.ps1

前置：載入管理工具

以「系統管理員」身分開啟 Windows PowerShell，先載入工具（每次開新視窗都要載一次）：

. C:\kmsh-ldap\ldap-admin.ps1

查（查詢帳號）

列出全部帳號

Ldap-List

查詢單一帳號

Ldap-Get M999

增（新增帳號）

格式：Ldap-Add <員編> "<密碼>"。新增後自動設定密碼並啟用。

Ldap-Add M999 "Kmsh@M999"
密碼須符合複雜度（含大小寫、數字或特殊符號，長度足夠）：純員編（如 M999）會被拒絕。建議初始密碼用 Kmsh@<員編>。另外，白板要能對應到單位／權限，該員編也需先在後台「人員管理」建入。

改（重設密碼）

格式：Ldap-Reset <員編> "<新密碼>"。同仁忘記密碼時使用。

Ldap-Reset M999 "New@Pass1"

停用／啟用

離職或暫停使用建議停用（保留資料、僅擋登入），需要時可再啟用：

Ldap-Disable M999
Ldap-Enable  M999

刪（刪除帳號）

格式：Ldap-Delete <員編>。永久移除該帳號。

Ldap-Delete M999
停用 vs 刪除：一般離職請用停用（保留歷史、可復原）；確定不再需要才用刪除（不可復原）。

注意事項

  • 每人專屬帳號、請勿共用（登入登出均留紀錄，供資安稽核）。
  • 員編＝帳號；密碼複雜度為強制要求（初始建議 Kmsh@<員編>）。
  • 新進人員：先在後台「人員管理」建入該員編（決定單位／權限），再用 Ldap-Add 建 LDAP 帳號。
  • 停用同步：後台「人員管理」停用不會自動關 LDAP 帳號，離職請另用 Ldap-Disable。
  • 白板顯示的看板頁為公開、不需登入；只有「管理後台」才需登入。

附錄：管理工具原始碼（ldap-admin.ps1）

位於 C:\kmsh-ldap\ldap-admin.ps1（須為 UTF-8 含 BOM，否則中文會亂碼）。內容如下：

# ldap-admin.ps1 — AD LDS (kmshldap @ 127.0.0.1:3890) 帳號管理工具
# 用法：以「系統管理員」開 PowerShell，先載入本檔：
#     . C:\kmsh-ldap\ldap-admin.ps1
# 再呼叫（員編即帳號）：
#     Ldap-List                         列出所有帳號
#     Ldap-Get   MB69                   查單一帳號
#     Ldap-Add   M999 "Kmsh@M999"       新增帳號並設密碼、啟用
#     Ldap-Reset MB69 "New@Pass1"       重設密碼
#     Ldap-Disable M999                 停用（不可登入，保留資料）
#     Ldap-Enable  M999                 重新啟用
#     Ldap-Delete  M999                 刪除帳號
Add-Type -AssemblyName System.DirectoryServices.Protocols
$P='System.DirectoryServices.Protocols'; $Srv='localhost'; $Port=3890; $PeopleDn='OU=people,DC=kmsh,DC=local'

function New-LdapConn {
  $c = New-Object "$P.LdapConnection"((New-Object "$P.LdapDirectoryIdentifier"($Srv,$Port)))
  $c.AuthType='Negotiate'; $c.SessionOptions.Signing=$true; $c.SessionOptions.Sealing=$true; $c.Bind(); $c
}
function _Udn($emp){ "CN=$emp,$PeopleDn" }
function _SetPwd($c,$emp,$pwd){
  $b=[System.Text.Encoding]::Unicode.GetBytes('"'+$pwd+'"')
  $m=New-Object "$P.DirectoryAttributeModification"; $m.Name='unicodePwd'; $m.Operation='Replace'; [void]$m.Add($b)
  $c.SendRequest((New-Object "$P.ModifyRequest"((_Udn $emp),$m)))|Out-Null
}
function _SetDisabled($c,$emp,$val){
  $m=New-Object "$P.DirectoryAttributeModification"; $m.Name='msDS-UserAccountDisabled'; $m.Operation='Replace'; [void]$m.Add($val)
  $c.SendRequest((New-Object "$P.ModifyRequest"((_Udn $emp),$m)))|Out-Null
}
function Ldap-List {
  $peo=[ADSI]"LDAP://${Srv}:$Port/$PeopleDn"
  $rows=$peo.psbase.Children | ForEach-Object { [pscustomobject]@{ 員編=[string]$_.Properties['cn'][0]; 停用=[bool]$_.Properties['msDS-UserAccountDisabled'][0] } } | Sort-Object 員編
  $rows | Format-Table -AutoSize
  Write-Host ("共 {0} 個帳號" -f $rows.Count)
}
function Ldap-Get($emp){
  $dn=_Udn $emp
  if(-not [ADSI]::Exists("LDAP://${Srv}:$Port/$dn")){ Write-Host "查無帳號：$emp"; return }
  $u=[ADSI]"LDAP://${Srv}:$Port/$dn"
  [pscustomobject]@{ 員編=[string]$u.Properties['cn'][0]; 停用=[bool]$u.Properties['msDS-UserAccountDisabled'][0]; 建立時間=$u.Properties['whenCreated'][0] } | Format-List
}
function Ldap-Add($emp,$pwd){
  if([ADSI]::Exists("LDAP://${Srv}:$Port/$(_Udn $emp)")){ Write-Host "帳號已存在：$emp"; return }
  $peo=[ADSI]"LDAP://${Srv}:$Port/$PeopleDn"; $u=$peo.Create('user',"CN=$emp"); $u.SetInfo()
  $c=New-LdapConn; _SetPwd $c $emp $pwd; _SetDisabled $c $emp 'FALSE'; $c.Dispose()
  Write-Host "已新增並啟用：$emp"
}
function Ldap-Reset($emp,$pwd){ $c=New-LdapConn; _SetPwd $c $emp $pwd; $c.Dispose(); Write-Host "已重設密碼：$emp" }
function Ldap-Disable($emp){ $c=New-LdapConn; _SetDisabled $c $emp 'TRUE'; $c.Dispose(); Write-Host "已停用：$emp" }
function Ldap-Enable($emp){ $c=New-LdapConn; _SetDisabled $c $emp 'FALSE'; $c.Dispose(); Write-Host "已啟用：$emp" }
function Ldap-Delete($emp){ $peo=[ADSI]"LDAP://${Srv}:$Port/$PeopleDn"; $peo.Delete('user',"CN=$emp"); Write-Host "已刪除：$emp" }
Write-Host "已載入 LDAP 帳號管理：Ldap-List / Ldap-Get / Ldap-Add / Ldap-Reset / Ldap-Disable / Ldap-Enable / Ldap-Delete"
