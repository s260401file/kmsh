# 後台總覽（管理系統）

規格書交付的「護理站電子白板管理系統」。**已併在 React 內**：路由 `/admin` → `pages/AdminPage.jsx`，受 `AuthContext` 登入保護（`ProtectedRoute`）。資料存 .NET API（[[_後台API總覽]]）＋ SQL Express。

> 為何要自建：民生用高榮系統、DB 在高榮，目前**僅開放 81 表報表庫**（[[HIS資料字典-可用資源]]）。其餘 HIS 有但未開放、或屬白板專屬 → 開放前在此後台維護過渡（待開放改接 API）。見 [[缺漏與申請清單]]。

## AdminPage 現有功能（皆多單位切換）
| 區塊 | 子項 | 狀態 |
|------|------|------|
| 公告管理 | 跑馬燈、佈告欄 | ✅ |
| 連絡資訊 | 值班人員、常用電話 | ✅ |
| 避難圖 | 圖片管理 | ✅ |

## 待建 — 後台開發清單（🔧自建，**可立即動工、不等高榮**）
> 來源：[[資料項對照表]] 的 🔧自建項。沿用既有模式：**多單位(unitCode)切換、CRUD、啟用/停用(isActive)、排序(sortOrder)**；權限 5 身分（管理員＋四區，第4次會議）。
> 為何可先做：這些是「院內操作性、HIS 根本沒有」的資料，與高榮資料開放**無相依**。

### 待釐清（非純自建，先別動工）
策略病人、照護提醒、病人註記（隔離/高危跌/運送等）→ 視高榮是否開放，見 [[資料項對照表]] ❓ 與 [[待辦清單]] C 區。

> **建議動工順序**：P1 護理排班/主護 → 白板基本 → 會診醫師值班 →（P2 各清單）。各模組可複製 公告/聯絡 的 CRUD 樣式快速產出。
