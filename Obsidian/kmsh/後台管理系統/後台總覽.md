# 後台總覽（管理系統）

規格書交付的「護理站電子白板管理系統」。**已併在 React 內**：路由 `/admin` → `pages/AdminPage.jsx`，受 `AuthContext` 登入保護（`ProtectedRoute`）。資料存 .NET API（[[_後台API總覽]]）＋ SQL Express。

> 為何要自建：民生用高榮系統、DB 在高榮，目前**僅開放 81 表報表庫**（[[HIS資料字典-可用資源]]）。其餘 HIS 有但未開放、或屬白板專屬 → 開放前在此後台維護過渡（待開放改接 API）。見 [[缺漏與申請清單]]。

## AdminPage 現有功能（2026-07 現況；皆多單位切換）
> 選單分「通用群組」＋「W52/ICU/OR/ER 各單位管理」＋「系統管理（僅管理員）」＋「我的帳號」。實際定義見 `React/src/pages/AdminPage.jsx` 選單陣列。

| 群組 | 子項 | 狀態 |
|------|------|------|
| 公告管理 | 跑馬燈、佈告欄 | ✅ |
| 連絡資訊 | 值班人員、常用電話 | ✅ |
| 避難圖 | 圖片管理 | ✅ |
| 護理排班（跨單位） | 我的病床（一床可多人）、排班、護理交班 | ✅ |
| **W52 管理** | 頁首設定、帳號設定、病人臨床補充、照護提醒、檢查/會診、三班護理師、顯示值班醫師、顯示照服員、顯示聯絡電話、查房表 | ✅ |
| **ICU 管理** | 頁首設定、帳號設定、病人臨床補充、檢查/會診、抗生素、三班護理師、顯示值班醫師、顯示照服員、顯示聯絡電話 | ✅ |
| **OR 管理** | 頁首設定、帳號設定、病人臨床補充、OR 手術派班、刷手/流動設定、OR 特殊交班、各科協助業務、溫溼度記錄 | ✅ |
| **ER 管理** | 頁首設定、帳號設定、病人臨床補充、檢查/會診、值班醫師排程、夜/假護理師排程、顯示值班醫師、醫師/照服員設定、三班護理師 | ✅ |
| **系統管理**（僅管理員） | 帳號設定（人員＋單位角色＋權限）、科別、醫師、照服員、操作稽核 | ✅ |
| 我的帳號 | 修改密碼（寫回 AD） | ✅ |

> 帳號連動 **AD LDS**：後台建立/更名/停用（不刪）/重設密碼；登入者可自改密碼。值班醫師採**中央排程**（ER 每月維護、全院共用 `OnCallRoster`），各站以「顯示值班醫師」引用當日值班；照服員採**主檔＋各站顯示**兩層（`CareAide`／`UnitCareAide`）。
