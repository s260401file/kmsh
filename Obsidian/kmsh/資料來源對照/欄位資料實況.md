# 欄位資料實況（有欄位 ≠ 有值）

> 來源：與院方資訊室 **智皓** 對話（2026-06-22）。結論：**HIS 雖有欄位，但民生實際多為空值**。
> 這比「有表≠有資料」更細：問題下沉到**欄位級**——同一表，有些欄位有值、有些全空。空值欄位＝**等同沒有 → 需自建或不顯示**。
> 關聯：[[HIS可用與缺漏分析]]（表/欄是否存在）、[[資料項對照表]]（來源/狀態）、[[資料庫Schema]]（自建與合併策略）、[[缺漏與申請清單]]。

## 狀態模型（四態）
| 態 | 意義 | 處置 |
|---|---|---|
| ✅有值 | 欄位存在且有可用資料 | HIS 直用 |
| ⛔空值 | 欄位存在但**全空** | 視同沒有 → 自建/不顯示 |
| ⚠不可用 | **值異常**（如時間欄亂）或**全表同一值**（無鑑別力）| 視同沒有 → 自建/不顯示 |
| ③無 | 字典無表/欄（未開放模組）| 自建（見 [[缺漏與申請清單]]）|

> ⛔⚠③ 都落入「自行開發」範圍 → 自建工作量比原估更大，需反映工時/排程。

### 對設計的關鍵衝擊
1. **DNR 全面無資料**（HPBASIC.HDNRSIGN/HICDNR、HCASE.HDNRCASE、ETROOTS DNR 類皆空）→ DNR **一律自建**。
2. **抗生素/化療旗標皆空**（UDANTFLG/UDDCJUST）→ 不能靠旗標；抗生素改以**藥名比對**（UDMDPNAM 比對抗生素清單）或自建旗標；化療同理或自建。
3. **會診**：僅 `ORCLVSNM`(VS 姓名)＋`ORPROCED` 可用；**去向 ORSUGEST、VS 代號 ORCLVSNO 空**。
4. **檢查**：`OROETYPE` 全同值（無法分類）、`ORSCHDT/ORSCHTM` 異常（排程時間不可靠）；報告 `RSSTATUS` 全同值（狀態不可用），`RTRESTXT`(文字) 可用、`RNRESVAL`(數值) 部分。
5. **手術 OPORDER 核心可用**（刀房/術式/主刀/助手/麻醉/狀態/來源/時間）→ 手術資訊可行；唯 NPO 時間異常、診斷/急刀/抗生素旗標部分空。
6. **轉院/候床不可用**：HOSPTRIN/HOSPTROU 空、HWBDDT 異常。
7. **過敏多為 NIL**＋`ERDISPAT` 不存在 → 過敏實質無資料。
8. **可用核心（好消息）**：床位 `HLOC`、科別 `HSECTION`、主治 `HDOCTOR`、診斷 `HDIAGNOS`、檢傷 `ETROOT`、手術 `OPORDER`、藥囑 `UDORDER`(藥名/時間) 皆正常。
9. **join 鍵不一致** → 聚合層須依各表用 ETHISNUM/ORHISNUM/RSHISNUM/HHISNUM 對應；ETROOTS 無病歷號需另解。

## 設計方式（因應「有欄位但空值」）

### 1. 合併粒度：row-level → **欄位級 COALESCE**
原 [[資料庫Schema]] 以 `PatientCensus.Source`（整列 HIS/MANUAL）混合，**不足以處理「同一病人，部分欄位有值、部分空值」**。改為**逐欄取值**：
```
顯示值(欄位) = HIS 值「非空白」? HIS 值 : 自建值
```
即對每個欄位做 COALESCE/NULLIF（空字串也視為空）。實作上病人核心仍以 `PatientCensus` 當自建覆蓋層，讀取時逐欄合併。

### 2. 欄位來源設定表 `FieldSourceMap`（驅動合併，免寫死）
沿用 [[資料庫Schema]] `MarkerTypeDef.SourceMode` 的精神，擴及**病人核心欄位**：每個欄位宣告來源模式，智皓回報後逐欄設定，未來院方補資料只需改設定。
```
FieldSourceMap: Id, EntityCode(patient/er…), FieldCode(HBLDTYPE…),
                SourceMode(HIS_ONLY/MANUAL_ONLY/HIS_THEN_MANUAL),
                IsEnabled, Note
```
- 確認**空值**的欄位 → `MANUAL_ONLY`（不查 HIS，直接自建/留空）。
- 確認**有值**的欄位 → `HIS_ONLY`。
- 不確定/過渡 → `HIS_THEN_MANUAL`（HIS 非空才用，否則自建）。

### 3. 「HIS 有」判定務必含「非空白」
所有 `HIS_THEN_MANUAL` 邏輯（含 `MarkerTypeDef.SourceMode`、`PatientMarker`）的「HIS 有值」判定，一律以 **`值非 null 且非空字串`** 為準——避免空值蓋掉自建值（本案核心教訓）。

### 4. 註記層（DNR/保密/安寧…）直接歸自建
HPBASIC 的 DNR/保密/安寧旗標既已確認空值，對應 [[資料庫Schema]] `MarkerTypeDef` 之 DNR 等，`SourceMode` 由 `HIS_THEN_MANUAL` 下修為 **`MANUAL_ONLY`**（待院方補資料再上調）。
