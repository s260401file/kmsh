# 缺漏與申請清單（先與民生討論 → 再向高榮提需求）

> 流程：**民生資訊室確認、界定範圍 → 整理正式需求單 → 院方向高榮(總院)申請 → 總院寫轉換/開 API**。

## ⭐ 原則（已更正）
- **民生用的是高榮提供的 HIS 系統，資料庫在高榮、不在民生**；高榮目前提供給民生的 ＝《醫療系統資料字典》的 **81 表報表庫**（[[HIS資料字典-可用資源]]）。
- **HIS 幾乎都有資料**——連護理排班，護理人員確實在 HIS 建立，只是**未開放給民生查詢/介接**。問題**一律是「高榮未開放/未提供」，不是「HIS 沒有」**。
- 策略：能向高榮申請開放就申請；開放前、時程緊迫者才**暫行自建**過渡，待 API 開放再切換（避免長期雙重輸入）。

---

## A. 向高榮申請開放（HIS 有，未開放給民生）

### A1. 已在備份報表庫（81 views）見到 → 直接申請開放這些 view/API
> 附表名讓高榮直接對應；現只開 1 支 [[Board_ER]]，其餘整批待申請。
- [ ] 病人基本 `AM.HPBASIC`；住院/床位/入出院 `AM.HCASE`·`AM.HLOC`·`AM.HSECTION`·`AM.HDISCHRG`
- [ ] 診斷 `AM.HDIAGNOS`；主治醫師(含主治/專師 HMDTYPE) `AM.HDOCTOR`
- [ ] 急診檢傷 `ER.ETROOT`/`ETROOTS`、重症通報 `ER.ERCRANN`
- [ ] 手術 `OR.OPORDER`；醫囑/檢查/會診 `OR.ORDER`；報告 `OR.RESULT`/`RESNUM`/`RESTEXT`
- [ ] 藥囑/抗生素/化療 `UD.UDORDER`（UDANTFLG/UDDCJUST）
- [ ] 註記候選：DNR `HPBASIC.HDNRSIGN`/`HCASE.HDNRCASE`、保密 `HPBASIC.HMRLOCK`、過敏 `MR.EMRTRE.HALERGY`

### A2. 報表庫未見、但 HIS 其他模組應有 → 請高榮從對應模組開放
> 這批掃描 81 views 為 0 筆，但 HIS 本身有（在排班 / 護理紀錄·評估模組）。
- [ ] **護理排班 / 主護（護理師負責床位）** — 護理人員已在 HIS 建立，未開放查詢
- [ ] **護理紀錄 / 評估**：管路（NG/CVC/導尿/氣管內管 ＋ 置入·換管日）★ICU、隔離、高危跌、運送方式/等級 A/B/C、氧氣設備、約束
- [ ] **會診**（`OR.ORDER` 有欄位，存取未開放）、**禁治療**

## B. 開放前的暫行自建（過渡，待 API 開放即切換）
> 因 9 月驗收時程，下列先以後台人工維護上線，**待高榮開放再改接 API**。
- 護理排班 / 主護（後台「員編勾選病床」）→ [[護理排班]]（過渡期有雙重輸入缺點）
- ICU 管路、隔離等若高榮短期無法開放：先評估人工維護或暫不顯示（視驗收）

## C. 白板專屬、本就後台維護（與 HIS 無關，非缺漏）
> 這些不是臨床資料、HIS 本就不會有，理應後台維護。
- 跑馬燈、佈告欄、聯絡電話、避難圖（✅ 已完成）
- 站別 / 護理長 / 病房主任；每日值班醫師 / 照服員 / 會診醫師「指派下拉」；照護團隊；RRT 顯示設定
- 開發清單見 [[後台總覽]]

## D. 資料存取面（民生資訊室處理，第5次會議卡關）

- [ ] 申請高榮**正式機**資料（測試機已關閉）
- [ ] 在 88/84 開放完整欄位、提供 ~100 View 清單
