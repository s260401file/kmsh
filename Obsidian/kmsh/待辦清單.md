## A. 介面 / 功能（第5次新增，待開發）
### ICU
- [ ] 首頁卡片加 **主治醫師**（床號＋姓名＋主治醫師）；DNR 等不擠首頁
- [ ] 醫師兩班以斜線「白班/夜班」；護理師三班
- [ ] **3F/4F 分頁切換**：4F（20床）為主頁、3F（5床）平時無病人預設隱藏，三角形按鈕切換；床數合計但分開顯示
- [ ] 新增 **會診醫師區**：依科別後台下拉（科別→醫師），免點病人即見當日各科會診醫師
- [ ] 標示 **策略病人**（機構後送病人）
- [ ] 取得並套用 3F ICU 平面圖（待 ICU 護理長提供）

### ER
- [ ] 新增 **會診醫師區**（字體不大）
- [ ] 聯絡資訊分「**值班人員**」（左）與「**常用電話**」
- [ ] 醫師班別：白班/夜班（急診僅白/夜，無白小大）

### OR
- [ ] **特殊交班**：盡量由系統帶入（流動護理師護理紀錄），撈不到先留白，避免重複登打
- [ ] 隔離 / **測謀**註記若可撈取，由病房一路帶到手術室

### 跨站 / 後台
- [ ] **主護指派**：後台建各站護理人員名單（員編＋姓名）＋護理人員以員編登入勾選負責病床（房間/床號加速）→ [[護理排班]]
- [ ] **測謀註記**（新註記類型，定義待確認）加入各站
- [ ] 後台 5 種權限身分（管理員＋四區管理者），導入登入（目前免帳密）
