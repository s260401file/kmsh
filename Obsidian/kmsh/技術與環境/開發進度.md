4 站 `/w52 /icu /or /er` 巢狀路由＋分頁。本階段重點：
- **病人註記 SVG 形狀系統**：共用模組 `React/src/utils/flagShapes.jsx`。10 形狀 × 實心/空心 = 20 標記（圓 / 正三角 / 方 / 五角 / 十字 / 紅心 / 水滴 / 太陽 / 星 / 右三角），依固定循環指派、不對應語意。對應第4次會議「W52 改圖形(圓/三角/方/愛心)、不足補顏色」。**W52 / ICU / ER 採用；OR 維持中文字**。技術用內嵌 SVG（fill 實心 / stroke 空心 / `currentColor` 上色）。
- **ER 檢傷 1–5 → A/B/C 三級**（A 重症 1-2、B 中症 3、C 輕症 4-5）：卡片徽章、彈窗、卡片邊框、急診統計（A/B/C 三欄）、大量傷患頁全改。
- **ICU 病況等級 穩定/重症/危急 → C/B/A 級**（僅顯示文字改，資料值不變）；配色 A 紅 / B 黃 / C 綠（第3次會議）。

- **ER 病室動態分區**：各區「區帶背景＋區名」（負壓隔離室/兒科留觀區/第一·二留觀區/急診手術室/急救室/第1·2診療區）；第2診療區移到 MER01 下方；右上新增**三班醫護人員面板**（資料 `MOCK_DATA.ShiftStaff`，含醫師，API-ready）。
