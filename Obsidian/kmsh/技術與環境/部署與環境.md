# 部署與環境

## IIS 站台
| 站台 | Port | 實體路徑 | 內容 |
|------|------|---------|------|
| `kmsh-whiteboard` | 80 | `C:\inetpub\wwwroot\kmsh-whiteboard` | React build 產物（白板＋後台）|
| `kmsh-api` | 5100 | `C:\inetpub\wwwroot\kmsh-api` | .NET API |

## 前端部署流程（React）
```
cd C:\WorkDir\Nursing Whiteboard\React
npm run build                      # 產出 dist/
# 備份現有站台 → robocopy /MIR dist → kmsh-whiteboard
```
- 部署前會先備份到 `C:\inetpub\kmsh-whiteboard_backup_<時間戳>`。
- `dist/web.config` 提供 SPA 路由 fallback（IIS）。
- 驗證：`http://localhost/` 回 200、index.html 指向新的 `assets/index-*.js`。

## 後端部署（.NET API）
- 編譯後佈署到 `kmsh-api`（:5100）。
- 前端 `services/` 走相對 `/api/...`，由同源/反向代理導到 API（見 [[系統架構]]）。

## 資料庫
- SQL Server **Express**（DB `Whiteboard`）。連線字串位於 API 專案設定（`appsettings*.json`）。
- **遷移腳本**：`API/kmsh-whiteboard/Database/schema_v*.sql`，目前已至 **v40**（`night_nurse`）。部署新功能前需**依序執行**尚未套用的版本（如 v26 值班排程、v33 溫溼度、v35 顯示值班醫師、v36/37 照服員、v38 聯絡電話、v40 夜/假護理師…）。可作為驗收「Table Schema／E/R Model 文件」素材（[[驗收項目分析]]）。
- **JWT／AD LDS**：登入經 101 主機 AD LDS 驗證後簽發 token（12hr）；相關設定於 `appsettings` 的 `Jwt`／LDAP 區段（[[00-LDAP總覽]]）。

## 尚待（驗收前）
- **HTTPS / TLS**：目前 API :5100、前端 :80 皆 http；合約要求對外服務上 SSL（[[驗收項目分析]] §二）。
- **閒置自動登出**：目前 token 12hr 到期才登出，專屬閒置逾時尚未實作（OR 檢視密碼逾時 `UnitInfo` v31 為另一機制）。
